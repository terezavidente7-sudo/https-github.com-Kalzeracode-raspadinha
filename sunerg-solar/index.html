A manutenção de energia solar é complicada?

Não. Em geral, a rotina é simples: inspeções preventivas, limpeza quando necessária e acompanhamento do desempenho do sistema para evitar perdas.

A Sunerg trabalha só com residências?

Não. O foco inclui residências, comércios e operações de maior porte, sempre com projeto dimensionado para o perfil de consumo.

Posso financiar o projeto?

Sim. O site já posiciona financiamento facilitado como parte do funil para que a decisão fique mais acessível.

Vocês fazem o projeto até a homologação?

Sim. A proposta é reduzir o atrito do processo e entregar um sistema pronto para operar com menos dependência do cliente em etapas técnicas.
