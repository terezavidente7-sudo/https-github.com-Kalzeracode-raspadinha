# Sunerg Solar

Site institucional e blog SEO da Sunerg Solar, recriado em uma estrutura nova, mais editorial e orientada a conversao.

## O que tem aqui

- Home nova com posicionamento, prova social e CTA forte
- Páginas institucionais e de serviço
- Blog com conteúdo para SEO local e educacional
- Formulário de contato com fluxo dedicado
- SEO base com `robots.txt`, `sitemap.xml`, canonical e JSON-LD

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
